# Just for Guidance

## What is the purpose of the website?

A site to discover educational podcast about certain topics

## What will the user be able to do?

1. See all podcast
2. Filter the podcast based on a category
3. Filter the podcast based on the language.
4. See all Local podcast
5. Filter all local podcast
6. See the platforms where those podcast can be listened to.
7. Click on an icon that will redirect to a platform where the user can listen to the podcast

## How will the user will be able to do those actions?

1. Once the page loads, all podcast are going to be loaded
2. A button will be used to filter the podcast by category or langage
3. The user will be able to click on an icon in order to open that podcast in X platform
